# Парақ — 3D онлайн кітапхана

Видеодағы көрініске ұқсатып жаңадан жасалған жоба. Бұл түпнұсқа paraqta.kz коды немесе дәл көшірмесі емес. Барлық 3D жиһаз бен кейіпкер кодпен жасалады; сырттан модель жүктеу қажет емес.

## Іске қосу

Node.js 20 немесе жаңа нұсқасын орнатыңыз. Терминалда:

```bash
npm install
npm start
```

Браузерде http://localhost:3000 ашыңыз. Алғашқы npm install үшін интернет керек; одан кейін Three.js те серверден беріледі.

## GitHub-қа салу

1. GitHub → New repository → Create repository.
2. Add file → Upload files арқылы осы архивтің ішіндегі файлдарды салыңыз. package.json мен server.js репозиторийдің түбірінде болуы керек.
3. Commit changes басыңыз.

GitHub кодты сақтайды. Бірге отыру және чат үшін Node.js сервері қажет. GitHub Pages және Streamlit осы нұсқаның серверін іске қоспайды.

## Интернетке шығару (Render)

Render-ден New → Web Service ашып, GitHub репозиторийін қосыңыз.

- Runtime: Node
- Build command: npm install
- Start command: npm start
- Health check: /health

Сервер PORT ортасының айнымалысын автоматты пайдаланады. render.yaml дайын. Тариф пен қолжетімділік платформаға байланысты; тегін сервер ұйықтап қалуы мүмкін.

Досыңызға жарияланған сайттың «Дос шақыру» батырмасымен сілтеме жіберіңіз. Бір бөлмеде 24 адамға дейін. Бір сервер процесін қолданыңыз; бірнеше инстанс үшін ортақ Socket.IO адаптері мен деректер қоймасы қажет.

## Басқару

- WASD / бағыттауыштар: жүру. Телефонда экрандағы бағыт батырмалары.
- Орындықты басу: отыру. «Тұру»: орнынан тұру.
- Экранды сүйреу: камера бұру. Тінтуір дөңгелегі: жақындату.
- Таймер: 25/50 минут оқу, 5 минут демалу; бастау, тоқтату, қалпына келтіру.
- ♫: браузерде жасалатын тыныш жаңбыр тәрізді фондық дыбыс.
- Бірдей бөлме коды: нақты басқа пайдаланушыларды көру және чат.

Көрінетін оқырмандар — қосылған нақты пайдаланушылар. Кітапханашы — сәндік кейіпкер. Таймер әр пайдаланушыға жеке. Бөлмелер мен чат жедел жадта: сервер қайта қосылса жойылады. Профиль, пароль, кітап файлдары, бейне/аудио қоңырау бұл нұсқада жоқ. Бөлме коды — құпиясөз емес. Бұл шағын топтарға арналған бастапқы нұсқа; ашық үлкен сервиске авторизация мен тұрақты база қосу қажет.

## Осы ортадағы тексеру

JavaScript синтаксисі тексерілді. npm реестріне қолжетімділік 403 қатесін бергендіктен, тәуелділіктер орнатылмады, серверлік тест пен браузердегі 3D көрініс осы ортада орындалмады. Өз компьютеріңізде npm install, npm test, npm start командаларын орындаңыз.
